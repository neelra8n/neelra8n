### What I've been building

**YieldFi** — core engineering team at a DeFi protocol founded by YC alumni. Scaled to **~$200M peak TVL, $5M+ yield paid out, 60,000+ wallets and 13+ chains across 40+ strategies.** I worked directly with the founders on product definition, not just delivery, and owned the entire frontend surface plus three production backend services.

- **GM Markets** — permissionless, wallet-native trading for tokenised stocks, ETFs, commodities and FX across Arbitrum, Base and Ethereum. Real-time vault data, rewards tracking, on-chain yield dashboards, `<300ms` perceived latency.
- **YieldFi V2 & V3** — multi-vault investing with points accrual across Curator-listed vaults, and yield-bearing token investing with major assets.
- **Curator Dashboard** — private analytics and control panel for vault managers: share analytics, token performance insights, configuration for new vault deployments.
- **Gateway, Vault & RWA services** — Node.js backends with Redis caching, consuming Alpaca APIs to power live stock charts, real-time trading data and portfolio positions.
- **yfi-components** — multi-brand component library on CSS design tokens. Cut new-product launch time 50–60%, powering 4+ brand rollouts, 7 applications and 50+ reusable components.
- **PerfDash** — API benchmarking, Lighthouse Web Vitals, build analysis and interaction-latency testing across multi-region, multi-device and throttled CPU/network. Cut p95/p99 latency pre-deploy.
- **Telegram Web App + marketing bot** — notifications, broadcast messaging, error reporting, user engagement.
